CMake Integration
-----------------

Let us consider a simple piece of C++ code:

.. literalinclude:: examples/cmake1/my_module.cpp
   :language: cpp

A complete CMake configuration file for this module is:

.. literalinclude:: examples/cmake3/CMakeLists.txt
   :language: cmake
   :linenos:

Brief explanation of the CMake file:

* **[Lines 1–19]** This section provides a standard CMake configuration for building a Python C++ extension.

  The ``Python_add_library`` command declares the extension using CMake’s  
  `FindPython <https://cmake.org/cmake/help/latest/module/FindPython.html>`_ module.

  - Note that the ``c2py`` library is fetched and linked to the module.  
    As ``c2py`` compiles quickly, this approach is recommended. It ensures that both the module and ``c2py``  
    are built with consistent compiler options and linked against the same Python interpreter.

* **[Line 21]** The option ``Update_Python_Bindings`` is defined.  
  When set to ``ON``, the bindings are generated using ``clair-c2py``.

* **[Line 28]** An ``add_custom_command`` is used to invoke ``clair-c2py``.

* **[Line 30]** The ``add_dependencies`` command ensures that the bindings are generated before the module is compiled.

Additional notes:

* ``clair-c2py`` automatically uses the `compile_commands.json` file generated by CMake to detect all include flags  
  from the project's linked libraries (targets).  
  This makes it unnecessary to pass compilation flags explicitly.  
  The ``-p`` option is used to specify the path to the `compile_commands.json` file.

* ``clair-c2py`` is a source-to-source code generation tool.  
  It generates the bindings into a file named ``my_module.wrap.cxx`` located in the **source directory**.

Compiling
.........

To compile the module, run the following commands:

.. code-block:: bash

   $ mkdir build
   $ cd build
   $ cmake .. -DUpdate_Python_Bindings=ON
   $ make -j 8

You can then use the module in Python:

.. code-block:: console

   >>> import my_module as M
   >>> a = M.MyClass(1, 2)
   >>> a.f(3)
   4
