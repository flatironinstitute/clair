About clair/c2py
****************

clair/c2py is a C++-to-Python bindings generator developed at the Center for Computational
Quantum Science of the `Flatiron Institute <https://www.flatironinstitute.org>`_, Simons Foundation.

It is an evolution of the `TRIQS/cpp2py <https://github.com/TRIQS/cpp2py>`_ tool, which has been
used in the `TRIQS <https://triqs.github.io>`_ project since 2014, and is fully backward compatible with it.

Authors
-------

clair/c2py is written and maintained by O. Parcollet, N. Wentzell, and T. Hahn.

Source code
-----------

The source is hosted on GitHub:

* `clair <https://github.com/flatironinstitute/clair>`_ — the Clang tooling that generates the bindings.
* `c2py <https://github.com/flatironinstitute/c2py>`_ — the C++20 runtime support library.

To report a problem, see :ref:`issues`.
